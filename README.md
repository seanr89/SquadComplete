# Squad Complete

Welcome to the Squad Complete project.

## Development Guidelines

**Important:** After each successful merge into the main branch, you must update the `CHANGELOG.md` file in each repository folder (`squad-api`, `squad-draft`, and `squad-func`) as well as any relevant documentation to reflect the changes.

## Structure

- `squad-api`: C# .NET Minimal API backend
- `squad-func`: Azure Functions for background tasks
- `squad-draft`: React frontend application built with Vite
